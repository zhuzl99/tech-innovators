## How to Take These Screenshots

### Method 1: Using Chrome DevTools (Recommended)

1. **Open the website** in Chrome
2. **Press F12** to open DevTools
3. **For Desktop:**
   - Press `Ctrl + Shift + P`
   - Type "screenshot"
   - Select "Capture full size screenshot"

4. **For Mobile/Tablet:**
   - Press `Ctrl + Shift + M` for device toolbar
   - Select device (iPhone 12, iPad, etc.)
   - Take screenshot using method above

### Method 2: Windows Snipping Tool

1. **Press** `Windows + Shift + S`
2. **Select** area to capture
3. **Save** the screenshot

### Method 3: Full Page Extension

1. **Install** "GoFullPage" Chrome extension
2. **Click** extension icon
3. **Download** full page screenshot

## Screenshot Editing Tips

### Recommended Tools

- **Windows:** Paint, Paint 3D, Snagit
- **Online:** Photopea.com, Canva.com
- **Professional:** Adobe Photoshop, GIMP

### Editing Checklist

- [ ] Crop to remove unnecessary parts
- [ ] Resize if too large (max 1920px wide)
- [ ] Add border for clarity (optional)
- [ ] Add caption below image
- [ ] Save as PNG for best quality
- [ ] Name files according to template

---

## Inserting Screenshots into Report

### In Microsoft Word

1. Click where you want the image
2. Insert → Pictures → From File
3. Select screenshot file
4. Add caption: Right-click → Insert Caption
5. Adjust size if needed

### In Google Docs

1. Insert → Image → Upload from computer
2. Add caption below image
3. Resize and position

### Formatting Tips

- **Alignment:** Center images
- **Size:** Keep consistent width (e.g., 6.5 inches)
- **Caption:** "Figure X: [Description]"
- **Quality:** Use high resolution
- **File size:** Compress if report is too large

## Additional Tips

### What Makes Good Screenshots

✅ **Clear and focused** - Shows the feature clearly
✅ **High resolution** - Text is readable
✅ **Proper zoom** - 100% zoom level
✅ **Consistent size** - All screenshots similar dimensions
✅ **No clutter** - Close unnecessary tabs/windows
✅ **Professional** - Use clean browser window

### What to Avoid

❌ Low resolution or blurry images
❌ Screenshots with personal bookmarks
❌ Browser developer tools visible (unless demonstrating)
❌ Inconsistent viewport sizes
❌ Desktop background visible
❌ Watermarks or editing artifacts
